# iX3 Themes

<img src="icon.png" width="72" align="left" alt="iX3 Themes icon">

Redraws the whole instrument cluster in one of seventeen themes, with an English / Kurdish (Sorani) settings page. Open **iX3 Themes** from the apps menu on the center screen.

Needs the **cluster-render** app. For the theme pictures, installing, the Waze map window, the Kurdish interface and how to make a theme, see the [main README](../../README.md).

Based on the work of FDX100, https://github.com/FDX100. Third-party notices are in `NOTICE`.
